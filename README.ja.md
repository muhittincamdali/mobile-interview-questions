モバイル開発者向けの面接の質問と回答集です。iOS、Android、Flutter、React Native、モバイルのシステム設計、行動面接を扱います。問題集には 142 問があり、それぞれ junior、mid、senior のいずれかのレベルが付いています。技術的な回答はすべて、根拠にした一次情報へのリンクを備えています。Apple、Android、Flutter、Dart、Kotlin、React Native のドキュメント、Swift Evolution の提案、MDN、RFC などです。51 件の回答にはコードが付いており、CI でテストが実行されます。そのため、回答の主張（actor は再入可能である、`Int(Double.nan)` は trap する、const の widget は再構築されない、`forEach` は await しない）は、繰り返し書かれているだけではなく、検証されています。

質問は GitHub 上でそのまま読めるほか、`interview` コマンドでターミナル上でクイズに挑戦したり、iPhone、iPad、Mac 向けの InterviewDeck アプリで学習したりできます。

## 主な特長

- **最新のプラットフォーム** — デフォルトの main-actor isolation と `@concurrent` を備えた Swift 6 言語モード、iOS 27 SDK でビルドするアプリが採用しなければならない scene ライフサイクル、Android 16 の大画面と predictive-back の変更、Dart 3 の pattern と extension type、そして React Native New Architecture。
- **自分で確かめられる回答** — 技術的な回答はすべて一次情報を引用しており、引用のない回答は linter が拒否します。
- **テスト済みのコード** — Swift の回答は macOS と iPhone シミュレータ上で Swift Testing により、Dart と Flutter の回答は `flutter test`（widget テストを含む）により、JavaScript の回答は `node --test` により実行されます。各テストには、検証している質問の名前が付いています。
- **学習ツール** — `swift run interview quiz` はトラックとレベルごとに質問をランダムに選びます。seed を指定すれば、どのマシンでも同じクイズを再現できます。
- **単一のフォーマットと lint** — 質問は構造が固定されたプレーンな Markdown なので、同じファイルが GitHub、コマンドライン、アプリ、そして [InterviewBank](#ライブラリを使う) ライブラリのすべてで使われます。

## クイックスタート

**1. 質問を入手する**

```sh
git clone https://github.com/muhittincamdali/mobile-interview-questions.git
cd mobile-interview-questions
```

Swift 6.2 以降が必要です。Mac では Xcode 26 以降、Linux では [Swift toolchain](https://www.swift.org/install/) を使います。Markdown ファイルを読むだけなら何も必要ありません。

**2. クイズを実行する**

```sh
swift run interview quiz --track ios --level senior --count 3
```

初回の実行ではツールがビルドされます。続いて 3 問と、使用した seed が表示されます。

```console
$ swift run interview quiz --track ios --level senior --count 3 --seed 7
Quiz: 3 of 12 questions · seed 7

1. [IOS-021 · senior · Memory management] Is `autoreleasepool` still useful in Swift?
2. [IOS-029 · senior · Swift concurrency] Where does a `nonisolated async` function run, and what do `nonisolated(nonsending)` and `@concurrent` mean?
3. [IOS-047 · senior · UIKit and the app life cycle] How do you run work in the background on iOS?

Answers: interview show <ID>, or repeat with --seed 7 --answers
```

**3. 回答を確認する**

```sh
swift run interview show IOS-026
```

回答、参考資料、そしてそのコードを検証するテストが表示されます（IOS-026 の場合は [ConcurrencyTests.swift](Tests/AnswerTests/ConcurrencyTests.swift)）。同じ seed のクイズに `--answers` を付けると、すべての回答を一度に表示できます。

## コマンド

| コマンド                                        | 内容                                                                               |
| ----------------------------------------------- | ---------------------------------------------------------------------------------- |
| `interview list --track flutter --level mid`    | 質問を一覧表示します。`--topic "Swift concurrency"` と `--search actor` も使えます |
| `interview show RN-012`                         | 1 つの質問を、回答、参考資料、テストとともに表示します                             |
| `interview quiz --count 10 --seed 42 --answers` | 1 〜 50 問の再現可能なクイズ                                                       |
| `interview stats`                               | トラックとレベルごとの質問数                                                       |
| `interview lint`                                | 質問ファイルを検査します。問題があると終了ステータス 1 になります                  |

すべてのオプションは `swift run interview --help` で確認できます。`--count 0`、`--count 1e3`、不明なトラックなどの不正な入力は、クラッシュせずに終了ステータス 2 で報告されます。

## 例：検証済みの回答

各質問は、ID、レベル、回答、参考資料を持つ Markdown のセクションです。次は [questions/ios/swift-language.md](questions/ios/swift-language.md) にある IOS-012 の冒頭です。

```markdown
## IOS-012: How do you convert a `Double` to an `Int` without crashing?

**Level:** mid · **Verified by:** [SwiftLanguageTests](../../Tests/AnswerTests/SwiftLanguageTests.swift)

`Int(someDouble)` truncates toward zero, and it **traps** (crashes) when the value is NaN,
infinite or outside `Int`'s range. ...
```

リンク先のテストは、回答に出てくるすべての変換を実行し、1 つでも挙動が異なれば失敗します。

```swift
@Test("IOS-012: Int(exactly:) returns nil where Int(_:) would trap")
func safeNumericConversion() throws {
    #expect(Int(exactly: 42.0) == 42)
    #expect(Int(exactly: 3.5) == nil)
    #expect(Int(exactly: Double.nan) == nil)
    let huge = try #require(Double("1e300"), "read at run time, like a value from JSON")
    #expect(Int(exactly: huge) == nil)
    #expect(Int(3.9) == 3, "Int(_:) truncates toward zero")
    // ...
}
```

これらのテストを書いたことで、公開前に下書きの誤りが修正されました。たとえば、リテラルで書いた `Int(1e300)` はそもそもコンパイルできないため、回答では実行時にしか分からない値を使って trap を示すようにしています。

## ライブラリを使う

`InterviewBank` ライブラリを使うと、質問ファイルの読み込み、lint、絞り込み、クイズの出題を自分の Swift コードから行えます。Swift Package Manager で追加します。

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/mobile-interview-questions.git", from: "2.0.0")
],
targets: [
    .target(name: "MyStudyTool", dependencies: [
        .product(name: "InterviewBank", package: "mobile-interview-questions")
    ])
]
```

```swift
import Foundation
import InterviewBank

let bank = try QuestionBank.load(from: URL(fileURLWithPath: "questions"))
let pool = bank.filter(QuestionFilter(track: .flutter, level: .mid))
for question in Quiz.pick(5, from: pool, seed: 2026) {
    print(question.id, question.title)
}
```

読み込みには上限があり（1 ファイルあたり 1 MiB、256 ファイル、1 ファイルあたり 500 問）、フォーマット上の問題はすべて、例外ではなくファイルと行を含む `Diagnostic` として返されます。
