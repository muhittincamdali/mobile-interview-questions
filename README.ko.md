모바일 개발자를 위한 면접 질문과 답변 모음입니다. iOS, Android, Flutter, React Native, 모바일 시스템 설계, 행동 면접을 다룹니다. 문제 은행에는 142개의 질문이 있으며 각 질문에는 junior, mid, senior 중 하나의 레벨이 붙어 있습니다. 모든 기술 답변은 근거로 삼은 1차 자료로 연결됩니다. Apple, Android, Flutter, Dart, Kotlin, React Native 문서, Swift Evolution 제안, MDN 또는 RFC 등이 그 예입니다. 51개 답변에는 CI에서 테스트가 실행하는 코드가 있어서, 답변이 내세우는 주장(actor는 재진입이 가능하다, `Int(Double.nan)`은 trap을 일으킨다, const 위젯은 다시 빌드되지 않는다, `forEach`는 await하지 않는다)이 단순히 되풀이되는 데 그치지 않고 검증됩니다.

질문은 GitHub에서 바로 읽을 수 있고, `interview` 명령으로 터미널에서 퀴즈를 풀거나 iPhone, iPad, Mac용 InterviewDeck 앱으로 공부할 수도 있습니다.

## 주요 기능

- **최신 플랫폼** — 기본 main-actor isolation과 `@concurrent`를 갖춘 Swift 6 언어 모드, iOS 27 SDK로 빌드하는 앱이 반드시 채택해야 하는 scene 생명 주기, Android 16의 대화면 및 predictive-back 변경 사항, Dart 3의 pattern과 extension type, React Native New Architecture.
- **직접 확인할 수 있는 답변** — 모든 기술 답변은 1차 자료를 인용하며, 인용이 없는 답변은 linter가 거부합니다.
- **테스트된 코드** — Swift 답변은 macOS와 iPhone 시뮬레이터에서 Swift Testing으로, Dart와 Flutter 답변은 `flutter test`(위젯 테스트 포함)로, JavaScript 답변은 `node --test`로 실행됩니다. 각 테스트는 검증하는 질문의 이름을 따릅니다.
- **학습 도구** — `swift run interview quiz`는 트랙과 레벨별로 질문을 무작위로 뽑습니다. 같은 seed를 쓰면 어느 기기에서든 같은 퀴즈가 반복됩니다.
- **하나의 형식, lint 적용** — 질문은 구조가 고정된 일반 Markdown 파일이므로, 같은 파일이 GitHub, 명령줄, 앱, 그리고 [InterviewBank](#라이브러리-사용하기) 라이브러리에 모두 쓰입니다.

## 빠른 시작

**1. 질문 받기**

```sh
git clone https://github.com/muhittincamdali/mobile-interview-questions.git
cd mobile-interview-questions
```

Swift 6.2 이상이 필요합니다. Mac에서는 Xcode 26 이상, Linux에서는 [Swift toolchain](https://www.swift.org/install/)을 사용하세요. Markdown 파일을 읽기만 한다면 아무것도 필요하지 않습니다.

**2. 퀴즈 실행하기**

```sh
swift run interview quiz --track ios --level senior --count 3
```

처음 실행하면 도구를 빌드합니다. 이어서 질문 세 개와 사용한 seed를 출력합니다.

```console
$ swift run interview quiz --track ios --level senior --count 3 --seed 7
Quiz: 3 of 12 questions · seed 7

1. [IOS-021 · senior · Memory management] Is `autoreleasepool` still useful in Swift?
2. [IOS-029 · senior · Swift concurrency] Where does a `nonisolated async` function run, and what do `nonisolated(nonsending)` and `@concurrent` mean?
3. [IOS-047 · senior · UIKit and the app life cycle] How do you run work in the background on iOS?

Answers: interview show <ID>, or repeat with --seed 7 --answers
```

**3. 내 답 확인하기**

```sh
swift run interview show IOS-026
```

답변, 참고 자료, 그리고 답변의 코드를 검증하는 테스트를 출력합니다(IOS-026의 경우 [ConcurrencyTests.swift](Tests/AnswerTests/ConcurrencyTests.swift)). 같은 seed의 퀴즈에 `--answers`를 붙이면 모든 답변을 한 번에 출력합니다.

## 명령

| 명령                                            | 기능                                                                                     |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `interview list --track flutter --level mid`    | 질문을 나열합니다. `--topic "Swift concurrency"`와 `--search actor`도 사용할 수 있습니다 |
| `interview show RN-012`                         | 질문 하나를 답변, 참고 자료, 테스트와 함께 보여 줍니다                                   |
| `interview quiz --count 10 --seed 42 --answers` | 1개에서 50개 사이의 질문으로 이루어진 반복 가능한 퀴즈                                   |
| `interview stats`                               | 트랙과 레벨별 질문 수                                                                    |
| `interview lint`                                | 질문 파일을 검사합니다. 문제가 있으면 종료 상태 1을 반환합니다                           |

전체 목록은 `swift run interview --help`로 확인하세요. `--count 0`, `--count 1e3`, 알 수 없는 트랙처럼 잘못된 입력은 충돌하지 않고 종료 상태 2로 보고됩니다.

## 예시: 검증된 답변

각 질문은 ID, 레벨, 답변, 출처를 갖춘 Markdown 섹션입니다. 다음은 [questions/ios/swift-language.md](questions/ios/swift-language.md)에 있는 IOS-012의 앞부분입니다.

```markdown
## IOS-012: How do you convert a `Double` to an `Int` without crashing?

**Level:** mid · **Verified by:** [SwiftLanguageTests](../../Tests/AnswerTests/SwiftLanguageTests.swift)

`Int(someDouble)` truncates toward zero, and it **traps** (crashes) when the value is NaN,
infinite or outside `Int`'s range. ...
```

링크된 테스트는 답변에 나오는 모든 변환을 실행하고, 하나라도 다르게 동작하면 실패합니다.

```swift
@Test("IOS-012: Int(exactly:) returns nil where Int(_:) would trap")
func safeNumericConversion() throws {
    #expect(Int(exactly: 42.0) == 42)
    #expect(Int(exactly: 3.5) == nil)
    #expect(Int(exactly: Double.nan) == nil)
    let huge = try #require(Double("1e300"), "read at run time, like a value from JSON")
    #expect(Int(exactly: huge) == nil)
    #expect(Int(3.9) == 3, "Int(_:) truncates toward zero")
    // ...
}
```

이런 테스트를 작성하면서 초안이 공개되기 전에 바로잡혔습니다. 예를 들어 리터럴로 쓴 `Int(1e300)`는 아예 컴파일되지 않으므로, 이제 답변은 실행 시점에야 알 수 있는 값으로 trap을 보여 줍니다.

## 라이브러리 사용하기

`InterviewBank` 라이브러리는 직접 작성한 Swift 코드에서 질문 파일을 읽고, lint하고, 필터링하고, 퀴즈로 출제합니다. Swift Package Manager로 추가하세요.

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/mobile-interview-questions.git", from: "2.0.0")
],
targets: [
    .target(name: "MyStudyTool", dependencies: [
        .product(name: "InterviewBank", package: "mobile-interview-questions")
    ])
]
```

```swift
import Foundation
import InterviewBank

let bank = try QuestionBank.load(from: URL(fileURLWithPath: "questions"))
let pool = bank.filter(QuestionFilter(track: .flutter, level: .mid))
for question in Quiz.pick(5, from: pool, seed: 2026) {
    print(question.id, question.title)
}
```

읽기에는 상한이 있으며(파일당 1 MiB, 파일 256개, 파일당 질문 500개와 보고되는 문제 100개), 모든 형식 문제는 예외 대신 파일과 줄 번호가 담긴 `Diagnostic`으로 반환됩니다.
