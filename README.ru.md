Вопросы и ответы для собеседований мобильных разработчиков: iOS, Android, Flutter, React Native, проектирование мобильных систем и поведенческие раунды. В банке 142 вопроса, каждый помечен уровнем junior, mid или senior, а каждый технический ответ ссылается на первоисточник, на который опирается: документацию Apple, Android, Flutter, Dart, Kotlin и React Native, предложения Swift Evolution, MDN или RFC. У 51 ответа есть код, который тест запускает в CI, поэтому утверждения в этих ответах (actor реентерабелен, `Int(Double.nan)` вызывает trap, const-виджет не перестраивается, `forEach` не ждёт) не просто повторяются, а проверяются.

Вопросы можно читать прямо здесь, на GitHub, проверять себя в терминале командой `interview` или учить в приложении InterviewDeck для iPhone, iPad и Mac.

## Основные возможности

- **Актуальные платформы** — языковой режим Swift 6 с изоляцией main-actor по умолчанию и `@concurrent`, жизненный цикл на основе scene, который обязаны принять приложения, собранные с SDK iOS 27, изменения Android 16 для больших экранов и predictive back, pattern и extension type в Dart 3, а также New Architecture в React Native.
- **Ответы, которые можно проверить** — каждый технический ответ ссылается на первоисточник, а ответ без ссылки linter отклоняет.
- **Протестированный код** — ответы на Swift запускаются через Swift Testing на macOS и в симуляторе iPhone, ответы на Dart и Flutter — через `flutter test` (включая тесты виджетов), ответы на JavaScript — через `node --test`. Каждый тест назван по вопросу, который он проверяет.
- **Инструмент для подготовки** — `swift run interview quiz` выбирает случайные вопросы по треку и уровню; с одним и тем же seed тот же квиз повторяется на любой машине.
- **Один формат, проверяемый linter** — вопросы — это обычный Markdown с фиксированной структурой, поэтому одни и те же файлы питают GitHub, командную строку, приложение и библиотеку [InterviewBank](#использование-библиотеки).

## Быстрый старт

**1. Получите вопросы**

```sh
git clone https://github.com/muhittincamdali/mobile-interview-questions.git
cd mobile-interview-questions
```

Нужен Swift 6.2 или новее: Xcode 26 или новее на Mac либо [Swift toolchain](https://www.swift.org/install/) на Linux. Чтобы просто читать Markdown-файлы, не нужно ничего.

**2. Запустите квиз**

```sh
swift run interview quiz --track ios --level senior --count 3
```

При первом запуске собирается сам инструмент. Затем он выводит три вопроса и использованный seed:

```console
$ swift run interview quiz --track ios --level senior --count 3 --seed 7
Quiz: 3 of 12 questions · seed 7

1. [IOS-021 · senior · Memory management] Is `autoreleasepool` still useful in Swift?
2. [IOS-029 · senior · Swift concurrency] Where does a `nonisolated async` function run, and what do `nonisolated(nonsending)` and `@concurrent` mean?
3. [IOS-047 · senior · UIKit and the app life cycle] How do you run work in the background on iOS?

Answers: interview show <ID>, or repeat with --seed 7 --answers
```

**3. Проверьте свой ответ**

```sh
swift run interview show IOS-026
```

Команда выводит ответ, ссылки на источники и тест, который проверяет его код ([ConcurrencyTests.swift](Tests/AnswerTests/ConcurrencyTests.swift) для IOS-026). Если добавить `--answers` к квизу с тем же seed, все ответы будут выведены сразу.

## Команды

| Команда                                         | Что делает                                                                               |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `interview list --track flutter --level mid`    | Выводит список вопросов; также доступны `--topic "Swift concurrency"` и `--search actor` |
| `interview show RN-012`                         | Один вопрос с ответом, источниками и тестом                                              |
| `interview quiz --count 10 --seed 42 --answers` | Воспроизводимый квиз из 1–50 вопросов                                                    |
| `interview stats`                               | Количество вопросов по трекам и уровням                                                  |
| `interview lint`                                | Проверяет файлы с вопросами; при любой проблеме код выхода 1                             |

Полный список команд выводит `swift run interview --help`. О неверном вводе, например `--count 0`, `--count 1e3` или неизвестном треке, сообщается с кодом выхода 2, а не аварийным завершением.

## Пример: проверенный ответ

Каждый вопрос — это раздел Markdown с ID, уровнем, ответом и источниками. Вот начало IOS-012 из [questions/ios/swift-language.md](questions/ios/swift-language.md):

```markdown
## IOS-012: How do you convert a `Double` to an `Int` without crashing?

**Level:** mid · **Verified by:** [SwiftLanguageTests](../../Tests/AnswerTests/SwiftLanguageTests.swift)

`Int(someDouble)` truncates toward zero, and it **traps** (crashes) when the value is NaN,
infinite or outside `Int`'s range. ...
```

Связанный тест выполняет каждое преобразование из ответа и падает, если одно из них ведёт себя иначе:

```swift
@Test("IOS-012: Int(exactly:) returns nil where Int(_:) would trap")
func safeNumericConversion() throws {
    #expect(Int(exactly: 42.0) == 42)
    #expect(Int(exactly: 3.5) == nil)
    #expect(Int(exactly: Double.nan) == nil)
    let huge = try #require(Double("1e300"), "read at run time, like a value from JSON")
    #expect(Int(exactly: huge) == nil)
    #expect(Int(3.9) == 3, "Int(_:) truncates toward zero")
    // ...
}
```

Написание этих тестов исправило черновики до публикации: например, `Int(1e300)` с литералом вообще не компилируется, поэтому теперь ответ показывает trap на значении, известном только во время выполнения.

## Использование библиотеки

Библиотека `InterviewBank` читает файлы с вопросами, проверяет их lint-правилами, фильтрует и составляет по ним квизы из вашего собственного кода на Swift. Добавьте её через Swift Package Manager:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/mobile-interview-questions.git", from: "2.0.0")
],
targets: [
    .target(name: "MyStudyTool", dependencies: [
        .product(name: "InterviewBank", package: "mobile-interview-questions")
    ])
]
```

```swift
import Foundation
import InterviewBank

let bank = try QuestionBank.load(from: URL(fileURLWithPath: "questions"))
let pool = bank.filter(QuestionFilter(track: .flutter, level: .mid))
for question in Quiz.pick(5, from: pool, seed: 2026) {
    print(question.id, question.title)
}
```

Чтение ограничено (1 MiB на файл, 256 файлов, 500 вопросов и 100 сообщений о проблемах на файл), а каждая проблема с форматом возвращается как `Diagnostic` с указанием файла и строки, а не как исключение.
